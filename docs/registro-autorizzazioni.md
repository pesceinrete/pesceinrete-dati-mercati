# Registro delle autorizzazioni al riuso

Un posto solo dove stanno le risposte scritte delle fonti. Il giorno che
qualcuno chiede "con quale titolo pubblicate questi prezzi", la risposta
deve essere un documento, non un ricordo.

| Fonte | Richiesta inviata il | A chi | Risposta | Data | Condizioni | Documento |
|---|---|---|---|---|---|---|
| Statistics Norway (SSB) | non necessaria | — | CC BY 4.0 | — | attribuzione, link alla licenza, indicazione delle elaborazioni | https://www.ssb.no/en/informasjon/copyright |
| Banca centrale europea | non necessaria | — | riuso con attribuzione | — | citare la fonte | https://www.ecb.europa.eu/services/disclaimer/html/index.en.html |
| Eurostat Comext | non necessaria | — | riuso con attribuzione | — | citare "Eurostat" | https://ec.europa.eu/eurostat/about-us/policies/copyright |
| FranceAgriMer, RNM | | | in attesa | | | |
| BMTI, Ittico dati | | | in attesa | | | |
| EUMOFA | | | in attesa | | | |

Quando arriva una risposta: compilare la riga, salvare la mail in PDF in
`docs/autorizzazioni/<fonte>-<data>.pdf` e aggiornare la colonna
"licenza" della fonte in `config/prodotti.py`. Se la risposta è negativa o
condizionata, togliere `pubblicato: True` alle specie interessate finché
le condizioni non sono soddisfatte.
